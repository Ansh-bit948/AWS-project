# Requirements coverage

The user's request controls scope. The supplied documents are reference plans; assertions about guaranteed free services, formal proofs and achieved targets are not treated as verified results.

| Requested item | Implementation/evidence | Practical boundary |
|---|---|---|
| Genuine access data | Five published HP Labs access matrices with original source files, hashes and count checks | Distinct matrices within one benchmark family; no fabricated university ERP records |
| User profiling | Matrix-derived grant counts, rarity, density, degree percentile and mined memberships | No HR attributes or event history invented |
| Role discovery | Exact access cohorts and greedy support-signature factoring | Bounded heuristic; no global optimality claim |
| Roles and permissions | Full role evidence, paginated catalogs, versioned RBAC export | Dataset labels are not deployable AWS IAM actions |
| Risk analysis | Explained rarity and density components, user/permission support | Review cues, no labeled threat accuracy |
| Permission optimization | WSC comparisons and explicit reconstructed grant checks | Representation reduction, not automatic removal of needed access |
| AI recommendations | Backend review queue and persisted real-feedback Q-learning | Approval required; learning abstains until actual review evidence exists |
| Dynamic management | Revoke/restore, active authorization, parent versions, conditional concurrency checks, audit | Application policy only; no live ERP credentials or connector were supplied |
| Reinforcement learning | Terminal offline Q-learning from actual administrator reviews | No simulated feedback, temporal outcome model, or causal safety claim |
| Frontend/backend/cloud | Responsive local UI, FastAPI/SQLite, AWS shared Lambda service | No public website traffic required |
| AWS highlights and cost | S3, Lambda, API Gateway, Cognito, DynamoDB, IAM, CloudWatch, Budget, SAM/CloudFormation, Access Analyzer | Free-plan/credits apply; budget does not cap spending |
| Real results/performance | Source-backed JSON evaluations, backend checks, actual AWS and browser verification | Host/dataset-specific measurements |
| CV/course report | Reproducible scripts, architecture, evidence exports, report and screenshots | Describe measured scope accurately |
| Possible patent | Dated research notes and prior-work boundaries | Novelty/patentability are unestablished |

Static benchmark matrices contain no temporal outcomes or administrator decisions. Feedback learning stays unavailable until at least five genuine review decisions across two users are recorded. Missing labels and rewards are not fabricated.
